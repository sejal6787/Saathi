

\# Saathi – Maternal and Child Healthcare Support Platform



Saathi is a healthcare support platform designed to support maternal and child healthcare through digital health records, pregnancy tracking, health event management, and technology-assisted healthcare services.



The project aims to improve access to organized maternal and child health information and support timely healthcare follow-ups.



\## Project Status



\- Backend: Under development, with core backend components implemented.

\- Flutter Frontend: In development.

\- Database: PostgreSQL.

\- Additional AI-assisted and healthcare features: Planned or under development, depending on implementation status.



\## Technology Stack



\### Backend

\- Python

\- FastAPI

\- PostgreSQL

\- SQLAlchemy

\- Pydantic



\### Frontend

\- Flutter

\- Dart



\## Core Project Modules



The project is structured around the following healthcare entities:



\- User

\- Mother

\- Pregnancy

\- Child

\- Health Events

\- Appointments



The backend uses a relational database structure to organize maternal and child healthcare information.
